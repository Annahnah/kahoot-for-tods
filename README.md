# Kahoot for Tods 🎮

A live, Kahoot-style quiz game built for toddlers and early learners. Players answer 
multiple-choice questions across Maths, Phonics, Reading, and "Our Island Jamaica" 
categories, with a countdown timer and a live leaderboard.

🔗 **Play it live:** https://codepen.io/AkinaSalguod/pen/WbNYzeQ

Built with React.
